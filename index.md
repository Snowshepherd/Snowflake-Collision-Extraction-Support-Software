# Snowflake Collision Event Extraction Support Software 

Version 1.0.0 

This software was developed to assist in extracting candidate 
snowflake collision events from snowfall videos. 

## Download 

The software is available for Windows. 

[Download the latest release] 

## Requirements 

- Windows 
- Binarized MP4 or AVI video 

## Contents 

- Executable software 
- Input
- Output 
- User manual 

## Basic Usage 

1. Download the ZIP file. 
2. Extract the ZIP file. 
3. Start the application. 
4. Open the sample video. 
5. Set the analysis parameters. 
6. Run the analysis. 
7. Check the output files. 

## Important Note 

The software is intended as a screening tool. 
Final identification of collision events requires visual verification.
